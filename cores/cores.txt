# Libretro cores for the PlayStation Classic - the set AutoBleem ships.
#
# One core name per line (libretro-super's name), comments start with #. `make cores` builds them in this
# order, so the ones a console is most likely to need come first - on the 2-core build server the whole
# list is a day's work and the first hour should already give something to install.
#
# Selection rule: what RetroBoot 1.2 shipped for the console (KMFD's km_* builds, 89 cores on the owner's
# stick) - cores known to run on the hardware - mapped to their libretro-super names. cores-full.txt is
# AutoBleem-NG's whole list (170), everything that is known to *build*; promote from there after a
# hardware test. RetroBoot cores with no equivalent here: app_launcher_rb (RetroBoot's own), imageviewer
# (built into RetroArch), emux_chip8 (libretro-super's `emux` rule makes four cores under other names),
# easyrpg (needs a cross-built liblcf) and ffmpeg (needs FFmpeg) - both disabled in NG's list, daphne
# (dead upstream - dirksimple is its successor), pcsx_rearmed_peops/_unai (GPU-plugin variants of the one
# pcsx_rearmed; PS1 games run in pcsx-ab anyway). KMFD's *_xtreme / 2016_bright / 2018 variants map to the
# plain upstream core.
